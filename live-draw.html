note for Anna, not visitors: this page connects directly from the browser to fal.ai over a persistent WebSocket — that's what makes sub-second updates possible, since a normal request/response round trip (like the identity machine's photo→portrait step) is too slow for continuous drawing. The connection authenticates through api/fal-proxy.js, which keeps your real fal.ai key server-side. You'll need to add FAL_KEY as a Vercel environment variable — see that file's comments for the exact steps. This is the one part of the whole build I could not verify end-to-end against a live account, so budget time to test and adjust the proxy against fal.ai's current documentation before a show.
