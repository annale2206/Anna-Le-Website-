note for Anna, not visitors: this page sends each drawn stroke to api/generate-draw.js — a plain request/response call, roughly every half second while you're actively drawing, same reliable pattern as the identity machine's portrait step. It's not true sub-second real-time (an earlier WebSocket-based attempt at that proved too fragile to get working reliably without live testing access), but it's dependable, and updates fast enough to feel responsive while drawing. Feedback frames are sent at a fixed 512x512 as JPEG (not the on-screen canvas size, not PNG) to keep payloads small and avoid 504s. You'll need FAL_KEY set as a Vercel environment variable — same key as before, no proxy or token setup needed for this simpler version.
