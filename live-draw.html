note for Anna, not visitors: this page now uses fal's realtime WebSocket mode via fal.realtime.connect() instead of a plain REST call per stroke — a persistent connection opens on the first stroke and stays warm, so there's no per-request cold start or Vercel function timeout to fight anymore. Requests to /api/fal/proxy are how the browser authenticates without exposing FAL_KEY — that file must exist at api/fal/proxy.js in the project (separate from the older api/generate-draw.js, which is no longer used by this page but left in place). Feedback frames are still sent at a fixed 512x512 JPEG to keep each message small. FAL_KEY must be set as a Vercel environment variable, same as before.
